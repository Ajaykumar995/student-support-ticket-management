# AI Usage Disclosure

## Project
Student Support & Ticket Management

## Purpose of AI Usage

AI tools were used as development assistance tools during the implementation and review of this project.

The AI assistance was used for:

- Understanding assignment requirements and translating them into application features.
- Discussing system architecture and project structure.
- Getting guidance on React.js frontend development.
- Getting guidance on Node.js, Express.js, and MongoDB backend development.
- Investigating and resolving development errors.
- Reviewing API structure and validation.
- Designing ticket management features, including:
  - Ticket status
  - Priority
  - Staff assignment
  - SLA tracking
  - Ticket ageing
  - Pending actions
  - Resolution and closure
- Improving UI structure and responsive styling.
- Reviewing code and identifying potential improvements.
- Preparing project documentation.

## Human Contribution

The developer was responsible for:

- Understanding the business requirements.
- Selecting application features and workflows.
- Integrating the frontend and backend.
- Configuring the database and environment.
- Running and testing the application.
- Investigating development issues.
- Reviewing and modifying AI-assisted suggestions.
- Making final implementation decisions.

AI-generated suggestions were not treated as automatically correct. Suggestions were reviewed and, where applicable, tested before being accepted.
