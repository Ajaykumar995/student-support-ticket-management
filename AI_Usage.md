# AI Usage Disclosure

## Project
Student Support & Ticket Management

## Purpose of AI Usage

AI tools were used as a development assistance tool during the implementation of this project.

The AI assistance was mainly used for:

- Understanding the assignment requirements and converting them into application features.
- Discussing the system architecture and project structure.
- Getting guidance on React.js frontend development.
- Getting guidance on Node.js, Express.js and MongoDB backend development.
- Debugging and resolving development errors.
- Improving API structure and validation.
- Designing ticket management features such as:
  - Ticket status
  - Priority
  - Staff assignment
  - SLA tracking
  - Ticket ageing
  - Pending actions
  - Resolution and closure
- Improving UI structure and responsive styling.
- Reviewing code and suggesting improvements.
- Preparing project documentation.

## AI-Assisted Features

The following project areas were developed with AI assistance:

### Authentication
- User registration and login
- JWT-based authentication
- Role-based authorization
- Student, Staff and Manager roles

### Ticket Management
- Ticket creation
- Ticket listing
- Ticket status management
- Ticket priority
- Ticket assignment
- Pending-action workflow
- Ticket ageing
- SLA calculation and breach detection
- Resolution and closure tracking

### Manager Dashboard
- Ticket statistics
- Staff assignment
- SLA monitoring
- Pending-action management
- Ticket status management

## Human Contribution

The project was implemented, configured, tested and reviewed by the developer.

The developer was responsible for:

- Understanding the business requirements.
- Selecting the application features and workflow.
- Integrating the frontend and backend.
- Configuring the database and environment.
- Running and testing the application.
- Debugging issues during development.
- Reviewing and modifying AI-assisted code.
- Making final implementation decisions.

AI-generated suggestions were not treated as automatically correct. Code was reviewed, modified where necessary, and tested before being included in the project.
